# 兼容性

## 三种不同条件

1. 程序能在操作系统运行：会话池是 Python 标准库程序，路径使用 pathlib；定时安排由宿主管理。
2. Codex 宿主提供所需工具：普通网页会话的列出、读取、发送；自动跟进另需原生定时检查能力与授权。接口可见性不是安装脚本能够赋予的权限。
3. 文件通道可用：网页实际能调用 Google Drive；若上传要求 file_uri，还须有网页自身已暴露的文件生成工具产生真实上传引用；使用者能按自己的方式取得文件。聊天正文和预览不等于上传引用。

三个条件分别检查。跨平台设计不代表所有宿主版本、套餐或插件组合都已验证。

## 运行要求

会话池要求 Python 3.10+。日常不需要 pip 安装第三方包。当前版本不再包含 JavaScript 等待脚本及其 Node.js 测试依赖。

每轮检查须核对实际工具返回；错会话、未知状态或解析异常不能用空闲替代。工具名称或结构变更需要核对适配，不能猜测继续运行。

## 平台状态

| 环境 | 设计目标 | 该发布候选的实际验证 |
| --- | --- | --- |
| Windows | 可运行会话池与当前宿主协作 | 见验证记录 |
| macOS | 相同程序与语义能力约定 | 未验证 |
| Linux 及其他系统 | 运行时与宿主满足条件时可评估 | 未验证 |

自动同步是否可用以操作系统实际工具和用户配置为准。显式下载与自动同步是不同交付方式。我们不提供或暗示所有平台都存在相同的 Google Drive 桌面客户端。

## 当前不承诺

跨最终答复、应用退出或断线持续工作；固定节省比例；自动切换模型或账号；任意插件都可调用；云端测试等价于本机；重新开会话可以解除权限或安全拒绝。

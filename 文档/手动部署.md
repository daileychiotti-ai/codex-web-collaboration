# 手动部署

先完成 [部署说明](部署.md) 的来源、宿主接口和配置位置核对。以下命令中的大写值是明确的待替换参数，不能原样登记为真实账户；所有 ID 都来自使用者实际会话。

## 运行程序

进入下载的仓库根。核查 Python 3.10+，初始化自己选择的数据库。

Windows PowerShell：

```powershell
py -3 --version
$dbPath = Read-Host '输入本地数据库的绝对路径'
py -3 '网页会话池/会话池.py' --db $dbPath init
```

macOS 或 Linux shell：

```sh
python3 --version
printf '输入本地数据库的绝对路径: '
IFS= read -r db_path
python3 '网页会话池/会话池.py' --db "$db_path" init
```

这只初始化本地状态，不会登录 ChatGPT，不会创建网页会话。继续登记前须通过实际语义工具读到用户授权会话及标记。

Windows 参数示例（先替换大写字符串）：

```powershell
py -3 '网页会话池/会话池.py' --db $dbPath profile-register --profile-id 'MY_PROFILE' --alias '我的账号' --sentinel-thread-id 'REAL_SENTINEL_ID' --sentinel-marker 'REAL_MARKER'
py -3 '网页会话池/会话池.py' --db $dbPath register-batch --profile-id 'MY_PROFILE' --thread-id 'REAL_UNUSED_THREAD_ID'
py -3 '网页会话池/会话池.py' --db $dbPath list --profile-id 'MY_PROFILE'
```

macOS 或 Linux 参数示例：

```sh
python3 '网页会话池/会话池.py' --db "$db_path" profile-register --profile-id 'MY_PROFILE' --alias '我的账号' --sentinel-thread-id 'REAL_SENTINEL_ID' --sentinel-marker 'REAL_MARKER'
python3 '网页会话池/会话池.py' --db "$db_path" register-batch --profile-id 'MY_PROFILE' --thread-id 'REAL_UNUSED_THREAD_ID'
python3 '网页会话池/会话池.py' --db "$db_path" list --profile-id 'MY_PROFILE'
```

标记包含 shell 特殊字符时不要直接拼接，使用安全的变量传值或结构化工具。程序帮助为 `--help` 或相应子命令 `--help`，不直接编辑 SQLite 表。

## 放置规则

备份经确认由当前宿主加载的 Markdown 全局指令文件，不能向任意 JSON、TOML 等应用配置追加 Markdown。无法确认文件类型、位置或作用域时不合并。按 [部署说明](部署.md) 实例化项目环境并合并 [全局节点](../配置/全局节点.md)，仅替换其唯一环境文件字段。不要把整份仓库 AGENTS 当全局配置覆盖。只有准确的一对开始/结束标记可以更新，保留其外所有原文。

技能安装是可选项，参考可以直接从仓库加载。需要安装时仅复制 `skills/网页执行/`，先核对目标位置及同名文件；不复制其他工具或历史文件。

确认环境文件中的仓库根可以读取 `文档/网页协作.md` 及其引用。已安装技能升级时也更新其入口引用；不把操作细则追加到全局块，不修改已配置的账号或数据库。首次部署和升级使用同一套路径定位方式。

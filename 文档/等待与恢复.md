# 等待、恢复与卸载

等待程序在 Codex 的 functions.exec 工具环境中加载，复用宿主真实会话接口。不是独立 Node/Python 服务或系统定时任务。

## 加载

读取仓库中的 `网页会话池/等待网页结果.js` 全文。Windows 可通过 `Get-Content -Raw -LiteralPath`，其他系统可通过安全引用路径的文本读取命令；命令须由本地根据已核对路径生成，不能拼接不可信网页文字。

确认读取成功、结果没有被截断且文件属于已核对发布版本后，将源码存入当前 functions.exec 脚本变量 `sourceText`。本例前三个变量必须由真实工具和租约取得，不能用标题猜值：

```javascript
// @exec: {"yield_time_ms": 1000, "max_output_tokens": 1200}
// sourceText：完整已核对本地脚本；lease：实际租约；dispatch：实际派发轮次与基线。
const waitWebResult = new Function('return (' + sourceText + ')')();
text(await waitWebResult(tools, {
  jobId: lease.jobId,
  threadId: lease.threadId,
  dispatchTurnId: dispatch.turnId,
  baselineMessageId: dispatch.baselineMessageId,
  intervalMs: 15000,
  maxWaitMs: 900000
}, {
  now: () => Date.now(),
  sleep: ms => new Promise(resolve => setTimeout(resolve, ms))
}));
```

这是嵌入宿主的调用片段，不是可以直接在终端运行的独立文件。`sourceText`、`lease`、`dispatch` 没有实际来源时不能运行。发送接受但还读不到本次用户轮次时先只读核对，不绑定旧轮次，不重发消息。

## 收取结果

宿主返回 Script running with cell ID 后保存真实编号。本地可以继续独立工作，续等通过 functions.wait 使用原 cell_id，单次阻塞不超过60秒；不要启动同任务第二个循环。终止等待使用该工具的 terminate，不取消网页任务或释放租约。

默认15秒间隔；单次函数调用默认预算15分钟，可配置预算上限1小时。这不是同一次派发的累计时限。收到 timeout 后由本地核对原任务仍在途且宿主允许继续，再以同任务、轮次与基线开始下一段；不重复派发，不因单段预算耗尽就要求用户回来报告完成。持续至新候选、明确失败、需要用户处理、用户暂停或宿主无法继续；程序自身不自动无限续等，不绕过宿主时限。单个接口自身超时另受宿主约束，预算不能保证强制终止卡住的接口。

多个已授权独立任务各自保留任务、会话、派发轮次、答复基线与真实 cell_id；同任务至多一个活跃等待。任务分别收取结果与验收，不因其中一个完成或超时就遗忘其他任务。并行须满足原生依赖、资源隔离与宿主并发限制；规则不证明多网页同时运行已经验证。

| 返回 | 含义与下一步 |
| --- | --- |
| candidate | 指定派发轮次存在新答复且会话空闲；accepted 仍为 false，另行完整读取并验收。 |
| timeout | 本段预算结束；核对原会话后可用同任务、轮次与基线续一段等待，不重发。 |
| read_error | 接口报错；停止循环，核对实际错误与副作用。 |
| protocol_error | 返回结构或会话不匹配；不能视为空闲。 |
| attention | 失败、中断或需关注；回到本地处理。 |

结束当前轮前收取或终止等待并说明未完成状态。程序不保证关闭应用、跨最终答复或断线存活，不默认创建定时自动化。

## 续接与异常

同角色澄清和返工保留租约与会话，发送一次新内容后绑定新派发轮次及基线。新独立角色另领会话。恢复先核对原租约、原会话新回复、输入版本、已完成文件与在途副作用。

停止等待不代表网页停止执行；网页回答结束不代表目标本机进程停止。明确安全拒绝停止被拒动作，不能更换会话或通道重做。

## 更新与卸载

安装记录保存本地：文件路径、修改前后摘要、备份位置和所拥有全局块。更新前比较当前文件与上次部署摘要；若用户后来改过，先比较并合并，不覆盖未知修改。

卸载只移除本方案拥有的全局块和确认属于本方案、且未被另改的技能文件。先查在途角色并处理等待。数据库、任务记录及用户文件默认保留；没有删除授权不清理运行目录。不要用旧整文件备份覆盖用户后来添加的其他配置。

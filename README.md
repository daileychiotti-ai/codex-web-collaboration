# 网页会话协作

让本地 Codex 负责讨论、决策和统筹，让普通 ChatGPT 网页会话承担完整角色任务。通过通用节点配置、会话池和工具内等待复用原生工作流程，项目文件由 Google Drive 交付。

这是配置模板和辅助程序组成的实验方案。它不增加账户额度，不授予工具权限，也不是独立浏览器机器人。

## 它如何工作

原生工作流 → 澄清、调查、推演、决策、规划、产出、执行、评估等通用节点 → 本地或网页承载。

这些节点不是固定八步。小任务和本机操作可留在本地；有完整背景的分析或产出可交给网页。原有流程中的独立审查、用户确认和真实测试仍然保留。

一次交接完整角色，网页直接处理，不递归外包。会话池保护占用与续接，等待程序只返回候选；本地再检查结果与文件。没有可用网页工具时继续原有本地工作，不虚报派发成功。

## 必要条件

- 宿主实际提供普通 ChatGPT 会话的列出/读取/发送接口，以及工具内异步等待能力。仅安装 Codex 或本仓库不保证这些能力可用。
- Python 3.10+，会话池仅使用标准库。Node.js 只用于开发者离线测试。
- 文件任务需要网页会话实际可用的 Google Drive 插件、使用者自己的项目位置，以及满足上传接口要求的真实文件来源。若接口只接受文件引用，还需要网页自身有生成该引用的文件工具；仅能输出正文不等于能上传。自动同步按系统实际能力配置，也可明确采用获准的手动取回。

采用跨平台设计，实际验证状态见 [验证记录](文档/验证记录.md)。macOS 或其他系统尚未验证的部分不等于已支持；宿主接口可见性与操作系统兼容性是不同问题。

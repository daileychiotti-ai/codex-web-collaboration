# 机器与文件

从实际项目说明取得 Drive 目录与文件身份，读取当次真实接口定义。名称相同不代表同一对象；通用 API 文档不证明当前插件暴露相应方法。

新增前核对父目录和同名对象。更新前读取准确文件 ID、版本或摘要，写后回读同一对象。代码、Markdown、文本和二进制保持普通文件格式；没有条件更新能力不能宣称原子写入，有未知并发修改先协调。

网页角色只能使用本轮实际可读输入；本机绝对路径不能冒充网页文件引用。参考图、生成图、下载原图与预览分别核对，不能以预览代替真实交付。

Google Drive 不执行命令。依赖真实本机应用、设备或运行的动作由本地在授权内完成，网页临时目录不能冒充本机目录。报告与日志可放入已授权交付范围，记录命令、工作目录、运行时、退出状态及相关输出。

按使用者的实际交付方式核对来源和到达。云端写入、同步到达、显式下载、实际运行分别记录；时间接近、同步图标、文件存在不证明内容正确。全项目同步须由使用者选择，不能从维护者的设置继承。

删除、移动及覆盖均需符合当前授权并明确对象，不以永久删除替代垃圾箱。运行中不抢写该批输入；日志仍写入不能宣称最终结果。

完成回报准确文件 ID、父目录、内容或版本及未核验项。有原始字节能力时可比较字节数和 SHA-256；没有就如实说明。恢复前核对原任务、在途动作和已完成副作用，不重做已完成写入。异常处理按环境文件中“仓库根”下 `文档/网页协作.md` 的“证据与异常”执行。

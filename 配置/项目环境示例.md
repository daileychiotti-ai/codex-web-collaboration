# 网页协作环境

这是待使用者实例化的模板；“未配置”不代表可用默认值。实际文件保存在本地配置目录，不提交公共仓库。

| 字段 | 当前值 | 核对依据 |
| --- | --- | --- |
| 发布版本 | 未配置 | 下载来源、标签或提交 |
| 仓库根 | 未配置 | 实际绝对路径 |
| 本地运行目录 | 未配置 | 用户选定的可写目录 |
| 会话数据库 | 未配置 | 上述运行目录中的准确数据库路径 |
| 当前账号 | 未配置 | 用户选择及可观察身份 |
| 会话登记来源 | 未配置 | 当前宿主实际读取的会话与用户授权 |
| 本地业务项目 | 未配置 | 本次实际项目路径 |
| Drive 项目位置 | 未配置 | 实际工具核对的目录 ID |
| 交付方式 | 未配置 | 已验证自动同步或获准显式取回 |
| 宿主能力 | 未配置 | 列出、读取、发送、工具异步等待的实际检查 |

凭据不写入本文或会话数据库。账号选择不等于模型核验。会话池程序和等待程序位于仓库根下 `网页会话池/`；日常调用必须显式传数据库路径。

缺少必要会话接口时不启用自动委托。文件任务缺少实际 Drive 能力或目的地时不宣称交付成功。可独立完成的纯文字任务可把完整输入和结果放在聊天中，明确未测试文件运输。
